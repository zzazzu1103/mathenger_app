# 📐 Mathenger — 한글(HWP) 수학 문제은행 · 학습지 생성기

기출문제가 모인 **한글(.hwp) 파일**과 문제를 정리한 **엑셀(.xlsx) 파일**을 등록해 두고,
단원·출처·키워드로 검색해서 고른 문제들로 **새 한글 학습지 파일**을 만들어 주는 웹 앱입니다.

> **수식·조건 박스·표·그림이 깨지지 않습니다.**
> 문제를 텍스트로 복사–붙여넣기 하는 방식이 아니라, 원본 HWP 파일 안의
> 문제 레코드(수식 개체·표·그림 포함)를 **바이트 그대로** 잘라 보관했다가
> 새 HWP 파일로 재조립하기 때문입니다.

## 설치 & 실행

```bash
pip install -r requirements.txt
python app.py
```

브라우저에서 http://127.0.0.1:5000 접속.

## 사용 순서

1. **가져오기** — 문제 모음 한글 파일(.hwp)과 정리 엑셀(.xlsx)을 업로드합니다.
   - 엑셀은 `기출DB` 시트의 열 순서(번호·연도·계열·출제월·출처·문항번호·과목·대단원·중단원·소단원·메인 아이디어·계산상의 포인트·표현상의 주의점)를 사용합니다.
   - **엑셀 행 순서와 한글 파일의 문제 순서가 같아야** 메타데이터가 올바르게 연결됩니다 (1행 ↔ 첫 번째 문제).
2. **문제 검색** — 과목/단원/출처/연도 필터와 키워드(본문·아이디어·포인트)로 검색하고, 원하는 문제를 **담기**.
3. **담은 문제** — 순서를 조정한 뒤 배치 방식(새 단 / 새 쪽 / 이어서)과 번호 매기기를 골라 **학습지 .hwp 다운로드**.

명령줄로도 쓸 수 있습니다:

```bash
python -m mathenger.cli import 문제모음.hwp 정리.xlsx
python -m mathenger.cli list
python -m mathenger.cli build 학습지.hwp 12 3 33   # 문제 ID 순서대로
```

## 동작 원리

```
원본.hwp ──분리──▶ 문제별 레코드 블록(바이트 그대로) + 검색용 텍스트 ──▶ SQLite
                                                                        │
엑셀 메타데이터(단원·출처·아이디어…) ──순서 매칭──────────────────────────┘

학습지 생성 = 원본의 FileHeader·DocInfo·BinData(그림) 스트림 복사
             + 선택한 문제 블록들만 이어 붙인 새 본문(Section0)
```

- **문제 경계 인식**: 문단의 세로 배치 정보(페이지 리셋)와 문제 종결 표지
  (①~⑤ 선택지 문단, "구하시오" 문단)를 조합해 문제 단위로 자릅니다.
  배점(`[4점]`)만 있는 문단이나 뒤따르는 그림 문단은 앞 문제에 붙입니다.
- **서식 보존**: 글꼴·문단 모양·수식이 참조하는 DocInfo와 그림(BinData)을
  원본에서 통째로 복사하므로 참조가 전부 유효합니다.
- **OLE 컨테이너**: 자체 구현한 CFB 라이터로 표준 HWP 5.0 컨테이너를 만듭니다.

## 한계 (현재 버전)

- **HWP 5.0 형식 전용** (암호화/배포용 문서, hwpx 미지원 — hwpx는 한글에서 .hwp로 저장 후 사용).
- **한 학습지에는 같은 원본 파일의 문제만** 담을 수 있습니다.
  원본마다 글꼴·수식 정의(DocInfo)가 달라 섞으면 서식이 깨질 수 있기 때문입니다.
  여러 원본을 쓰려면 원본별로 학습지를 나눠 만들어 주세요.
- 문제가 여러 단(칼럼)에 걸쳐 있거나 문서 구조가 크게 다르면 경계 인식이 어긋날 수
  있습니다. 가져오기 후 문제 수가 엑셀 행 수와 다르면 경고가 표시됩니다.
- 웹 화면의 미리보기는 텍스트만 보여줍니다(수식·그림 자리 생략).
  실제 학습지에는 원본 그대로 들어갑니다.

## 개발

```bash
pip install pytest
python -m pytest tests/            # 단위 테스트

# 실제 파일로 통합 테스트 (저작권 문제로 저장소에는 포함하지 않음)
MATHENGER_TEST_HWP=문제모음.hwp MATHENGER_TEST_XLSX=정리.xlsx python -m pytest tests/
```

구조:

| 경로 | 역할 |
|---|---|
| `mathenger/hwp/records.py` | HWP 5.0 레코드 파싱/직렬화 |
| `mathenger/hwp/reader.py` | OLE 컨테이너 읽기 (olefile) |
| `mathenger/hwp/splitter.py` | 문제 단위 분리 알고리즘 |
| `mathenger/hwp/cfb.py` | OLE(CFB) 컨테이너 쓰기 (자체 구현) |
| `mathenger/hwp/builder.py` | 학습지 HWP 조립 |
| `mathenger/db.py`, `mathenger/importer.py` | SQLite 저장소·엑셀 임포트 |
| `mathenger/worksheet.py` | 학습지 생성 서비스 |
| `app.py`, `templates/`, `static/` | Flask 웹 UI |
| `mathenger/cli.py` | 명령줄 도구 |

데이터는 `instance/mathenger.db`(SQLite)에 저장되며 원본 HWP 파일도 함께 보관됩니다.
